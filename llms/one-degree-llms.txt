# One Degree

> One Degree is a California 501(c)(3) nonprofit that helps low-income and underserved people find and access life-changing benefits and social services. Its Resource Server API exposes a curated, community-maintained database of social-service resources — organizations and the opportunities (programs/services) they offer, plus locations, phones, schedules, ratings, tags, comments, images, properties, guides, and housing properties. Read-focused REST over https://data.1degree.org/v1, authenticated with an api_key query parameter (HMAC-SHA256 request signatures for write verbs). Resource data is licensed CC BY-NC 4.0.

## APIs

- [One Degree Resource Server API](https://github.com/1deg/resource-server-api-docs): REST API for social-service organizations, opportunities, locations, and housing — base URL https://data.1degree.org/v1
